CSS=Cascading Style Sheets

CSS is used to style the HTML elements. It allows you to change the appearance of your web pages, including colors, fonts, layouts, and more. CSS can be applied inline,internally within a style tag , or externally through a separate .css file. By using CSS, you can create visually appealing and responsive designs for your websites. CSS can be applied in three main ways:
  1. Inline CSS: This method involves adding the CSS styles directly to the HTML elements using the "style" attribute. For example, you can change the color of a paragraph by adding style="color: blue;" to the <p> tag.
  2. Internal CSS: This method involves placing the CSS styles within a <style> tag in the <head> section of your HTML document. This allows you to define styles for multiple elements on the same page.
  3. External CSS: This method involves creating a separate .css file that contains all your CSS styles. You can then link this file to your HTML document using the <link> tag in the <head> section. This is the most efficient way to manage styles for multiple pages.

By using CSS, you can create visually appealing and responsive designs for your websites. It allows you to separate the content (HTML) from the presentation (CSS), making it easier to maintain and update your web pages.

Understanding CSS Syntax

CSS syntax consists of selectors and declarations. A selector targets the HTML element you want to style, while declarations define the styles to be applied. Declarations are enclosed in curly braces and consist of property-value pairs.

For example, the following CSS rule sets the color of all paragraphs to blue:

p { color: blue; }

In this example, p is the selector, and color: blue; is the declaration that sets the text color to blue.

CSS Selectors

CSS selectors allow you to target specific HTML elements based on their type, class, ID, or other attributes. Some common selectors include:

  • Element Selector: Targets all instances of a specific HTML element. For example, p targets all paragraphs.
  • Class Selector: Targets elements with a specific class attribute. For example, .my-class targets all elements with the class "my-class".
  • ID Selector: Targets a single element with a specific ID attribute. For example, #my-id targets the element with the ID "my-id".
  • Attribute Selector: Targets elements based on their attributes. For example, [type="text"] targets all input elements with the type "text".

Internal CSS

Internal CSS allows you to define styles within the <style> tag in the <head> section of your HTML document. This is useful for applying styles to a single page without creating a separate CSS file.

SYNTAX

<head>
<style>
p { color: blue; }
</style>
</head>

External CSS

External CSS allows you to define styles in a separate .css file and link it to your HTML document using the <link> tag in the <head> section. This is the most efficient way to manage styles for multiple pages.

EXTERNAL CSS FILE LINKING

SYNTAX

<head>
<link rel="stylesheet" href="style.css">
</head>

<head> is the section of the HTML document where you can include metadata, links to external resources, and other information about the document.
<link> is an HTML element used to link external resources, such as stylesheets or scripts, to the HTML document.
<link> connects an external resource to the HTML document.
rel="stylesheet" tells the browser that the resource is a stylesheet.
href="style.css" tells the browser which CSS file to load.
